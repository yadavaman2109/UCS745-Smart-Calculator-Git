## Overview
A lightweight Python CLI calculator created to demonstrate Git & GitHub version control workflows, branching, merging, and intentional merge conflict resolution.

## Current Version & Features
- **Version:** `1.2.0 (Scientific + Precision Edition)`
- **Operations:** `add`, `subtract`, `multiply`, `divide`, `power`, `modulus`
- **Output Format:** Configurable decimal precision with scientific notation (`[LOG] OP(a, b) -> val`)

python calculator.py
